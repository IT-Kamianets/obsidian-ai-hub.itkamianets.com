## 1. Обзор проекта и концепция

### 1.1 Назначение
**Obsidian AI Hub & Knowledge Manager** — это персональный мультимодальный AI-ассистент и менеджер базы знаний в виде современного SPA (React + TypeScript + Tailwind CSS). Приложение создано для автономной оцифровки информации (аудиозаписи, OCR документов, фото) и прямого двустороннего управления персональным хранилищем (Vault) Obsidian.

### 1.2 Архитектурные принципы
1. **24/7 Single Source of Truth (Server-First Storage):**  
   Основное хранилище развернуто на выделенном домашнем сервере внутри изолированного Docker-контейнера (`linuxserver/obsidian` с виртуальным дисплеем Xvfb). Взаимодействие происходит по защищенному протоколу через плагин **Obsidian Local REST API** (порт `:27124`), проксируемый Caddy reverse-proxy с доверенным TLS.
2. **Безопасность BYOK (Bring Your Own Key):**  
   Клиентское приложение работает без промежуточных облачных серверов и телеметрии. Запросы к LLM (Gemini 2.0 Flash / GPT-4o-mini) и сервисам транскрипции (Groq Whisper Cloud API) выполняются напрямую с устройства пользователя по личным API-ключам, защищенным в Keystore/Secure Store.
3. **Decoupled Workstation Sync:**  
   Основной рабочий ПК не является точкой отказа. Синхронизация между ПК и 24/7 домашним сервером осуществляется через одноранговый Syncthing с исключением файлов интерфейсного кэша (`.stignore` блокирует `workspace.json`).
4. **Local-First & Fault Tolerance (SQLite Queue):**  
   При потере связи с домашним сервером запросы и мультимодальные файлы не теряются, а сохраняются в локальную SQLite-очередь (`op-sqlite` / IndexedDB). Очередь разделена на 2 стадии:
   - `RAW_EXTRACT`: необработанное аудио или фото при отсутствии глобального интернета;
   - `READY_FOR_VAULT`: готовые Markdown-файлы и команды при недоступности сервера Obsidian.  
   При восстановлении сети фоновый воркер автоматически синхронизирует очередь с сервером.
5. **ReAct Loop & Tool Calling:**  
   AI-агент выполняет циклы рассуждения и действий: поиск по хранилищу (`search_vault`), чтение контекста (`read_note`), составление плана дня (`manage_daily_plan`), обновление задач (`update_task_status`) и модификация файлов (`create_note`, `append_to_note`).

## 4. Детальное текущее состояние (Что уже реализовано)

### 4.1 Презентационный лендинг (Маршрут: `/`)
- **Hero-секция:** Заголовок «Obsidian AI Hub & Knowledge Manager», подзаголовок об автономной оцифровке заметок, аудио (Groq Whisper) и OCR через Obsidian Local REST API (`:27124`). Полная поддержка i18n (`ru`, `uk`, `en`).
- **Секция преимуществ:** 4 карточки с полной локализацией:
  1. *24/7 Single Source of Truth:* Локальный REST API на домашнем сервере.
  2. *Мультимодальный захват (Multimodal Capture):* Распознавание речи Groq Whisper STT (< 1 с) и OCR через ML Kit.
  3. *ReAct AI-агент (ReAct AI Agent):* Интеллектуальный цикл планирования задач, поиска и структурирования.
  4. *Локальная надежность (BYOK):* Прямые ключи в Keystore и очередь SQLite.
- **Интерактивный терминал-превью:** Отображение статусов Docker, Caddy TLS-прокси и задержки отклика (локализовано).
- **Модальное окно входа / регистрации:**
  - Полностью переведено на выбранный язык (заголовки, бейджи, подсказки, поля ввода, чекбокс Secure Store).
  - **Кнопка-крестик (✕):** В правом верхнем углу (и клик по фону) **закрывает модалку**, оставляя пользователя на лендинге.
  - **Кнопка демо-входа:** Под кнопкой входа расположена лаконичная ссылка **«Войти в демо-режиме →»** (локализовано), по клику на которую пользователь мгновенно перенаправляется на `/chat`.
  - В шапке доступен быстрый селектор языка (`RU`, `UK`, `EN`).

### 4.2 Основной рабочий интерфейс ассистента (Маршрут: `/chat`)
- **Чистый старт при входе:** При переходе с авторизации или демо-кнопки открывается чистый диалог.
- **Экран приветствия (Empty State):** В центре нового диалога отображается карточка с вопросом «Чем могу помочь сегодня?» и 4 интерактивными подсказками:
  - `🎯 Спланировать задачи на день` (анализ вчерашнего дня и генерация задач с приоритетами);
  - `🎙️ Записать голосовую заметку (STT)` (распознавание речи и запись в `Inbox/Quick_Memos.md`);
  - `📷 Распознать документ (OCR)` (извлечение текста в Markdown с YAML);
  - `🔍 Исследовать структуру Vault` (поиск по проектам и проверка связей).
- **Синтаксис Obsidian Tasks:**
  - Задачи вида `- [ ] ... 📅 YYYY-MM-DD` полностью интерактивны.
  - Клик по чекбоксу мгновенно переключает статус в `- [x]`, визуально зачеркивает текст, обновляет файл `Daily/2026-09-28.md` и эмулирует вызов инструмента `update_task_status`.
  - Отображаются цветные бейджи приоритетов (`⏫ Высокий`, `🔼 Средний`, `🔽 Низкий`) и дат.
- **Интерактивные чипы Wiki-ссылок `[[...]]`:**
  - Ссылки на файлы (например, `[[Daily/2026-09-28.md]]`, `[[Projects/Architecture.md]]`) выводятся как фиолетовые интерактивные чипы.
  - Клик по ссылке открывает модальное окно предпросмотра заметки (`NoteModal`).
- **Сворачиваемый ReAct-аккордеон (ToolCallsAccordion):**
  - Шаги рассуждения и вызовы инструментов агента (`search_vault`, `read_note`, `manage_daily_plan`) объединены в компактную плашку:
    `⚙️ Использовано инструментов: X (search_vault, read_note) ✓ Выполнено ▾`
  - По клику аккордеон плавно раскрывается, отображая затронутые файлы и детализированные аргументы с результатами.
- **Поле ввода (Input Bar):**
  - Закреплено внизу, с автопереносом строк (`rows={2}`) и поддержкой отправки по `Enter`.
  - **Кнопки быстрых подсказок над инпутом:** Расположены строго в одну строку без горизонтального скроллбара (`overflow-hidden`, `no-scrollbar`, `flex-auto`), отображают полные названия на RU, UK и EN без обрезки и дублирования эмодзи/иконок.
  - Кнопка **«Голос»** активирует визуальный эффект активной записи: пульсирующий красно-фиолетовый индикатор звуковой волны, живой счетчик `● Запись звука 00:0X` и кнопку быстрой транскрипции в текст через Groq Whisper.
  - Кнопка **«OCR»** открывает симулятор распознавания страниц книг, чеков и накладных.
  - Кнопка **«Файл»** позволяет прикрепить документ с отображением бейджей.
- **Правая выдвижная шторка (Sidebar Drawer):**
  - Расположена справа, сворачивается/разворачивается кнопкой в шапке (на смартфонах открывается как overlay-шторка с затемнением).
  - Кнопка создания нового диалога с иконкой `<Plus />` (создает свежий чистый сеанс без дублирования знака «+»).
  - История диалогов с группировкой по датам («Сегодня», «Вчера», «Прошлые 7 дней») и возможностью удаления.
  - Блок «Быстрый доступ к Vault» со списком активных файлов (клик открывает предпросмотр).
  - **Статус соединения:** Внизу шторки строго над кнопкой настроек размещен индикатор `● REST Hub: Online :27124 (14ms)`. Дублирование статуса из верхней шапки удалено.
- **Сетка и геометрия:** Центральная колонка диалога, сообщения и инпут-бар расширены до `max-w-4xl` с центрированием `mx-auto`, устраняя пустые поля по бокам на широких мониторах.

### 4.3 Страница настроек (Маршрут: `/settings`)
- **Раздел «Внешний вид и локализация» (размещен первым блоком):**
  - **Переключатель тем (Theme Selector):** 3 интерактивные радио-карточки с иконками и превью цветовой палитры:
    - ☀️ **Светлая (Light):** чистый фон `#f8fafc`, белый кард `#ffffff`, глубокий текст `#0f172a`.
    - 🌙 **Obsidian Dark (по умолчанию):** фирменная графитовая палитра `#0c0e14`, `#171c2b`, `#2a324b`.
    - 🔘 **OLED / True Black:** глубокий чёрный `#000000` для OLED-экранов.
    - Тема мгновенно переключается на корневом контейнере (`[data-theme="..."]`) и сохраняется в `localStorage`.
  - **Переключатель языка (Language Selector):**
    - 🇷🇺 Русский (`ru`), 🇺🇦 Українська (`uk`), 🇬🇧 English (`en`).
    - Сегментированные кнопки с флагами; при смене языка весь интерфейс динамически обновляется.
- **Obsidian Local REST API Hub:** Server URL (`https://vault.internal.local`), порт `27124`, токен `OBSIDIAN_API_KEY`, статус TLS-прокси Caddy и кнопка проверки пинга (~14 мс).
- **BYOK Провайдеры:** поля ввода `GROQ_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY` с кнопками переключения видимости (маскирование пароля).
- **Офлайн-очередь SQLite:** таблица монитора задач `sync_job_queue` со стадиями `RAW_EXTRACT` и `READY_FOR_VAULT`, счетчиком повторов и кнопкой ручной синхронизации.
- **Переключатель Offline Mode:** возможность вручную симулировать отключение от сервера и видеть накопление задач в очереди SQLite.
- Кнопка возврата в шапке: «← Назад в чат».

## 5. Состояния (State Management) и хранение данных

Центральный контекст `AppContext.tsx` управляет следующим реактивным состоянием:

```typescript
// Ключевые поля контекста AppContext:
route: AppRoute;                  // '/' | '/chat' | '/settings'
isAuthenticated: boolean;        // Статус авторизации / демо-доступа
isAuthModalOpen: boolean;        // Открыто ли окно входа
theme: AppTheme;                 // 'light' | 'dark' | 'oled' (персистентно в localStorage)
language: AppLanguage;           // 'ru' | 'uk' | 'en' (персистентно в localStorage)
t: Translations;                 // Текущий словарь локализации
sessions: ChatSession[];         // Список всех чатов
activeSessionId: string;         // ID активного диалога
notes: Record<string, VaultNote>;// Файлы хранилища Obsidian
selectedNotePath: string | null; // Путь заметки, открытой в модалке предпросмотра
sqliteJobs: SQLiteJob[];         // Задачи локальной офлайн-очереди
settings: AppSettings;           // Параметры сервера, порты, API-ключи, offlineMode
isSidebarOpen: boolean;          // Состояние правой выдвижной шторки
toasts: ToastState[];            // Очередь всплывающих тостов
multimodalModal: 'voice' | 'camera' | null; // Активная модалка захвата
```

### Ключи в `localStorage`:
- `obsidian_hub_theme`: `'light'` | `'dark'` | `'oled'`
- `obsidian_hub_lang`: `'ru'` | `'uk'` | `'en'`

## 8. Инструкция для новой AI-сессии

Если вы начинаете новый сеанс работы с этим проектом, следуйте этим правилам:

1. **Контекст проекта:** Проект представляет собой полностью готовое SPA-приложение на React 19 + TypeScript + Vite + Tailwind CSS v4. Все экраны (`/`, `/chat`, `/settings`), переключение тем, мультиязычность и ReAct-симуляция работают без сбоев.
2. **Сохранение готовой логики:**
   - Никогда не ломайте логику модалки авторизации: крестик (✕) должен закрывать окно, а вход в демо-режим осуществляется по кнопке «Войти в демо-режиме →».
   - Не возвращайте индикатор сервера в шапку чата — он должен оставаться только внизу сайдбара над кнопкой настроек.
